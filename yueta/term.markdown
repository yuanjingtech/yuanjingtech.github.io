# 用户条款

最后更新日期：2026-11-12

下载、安装或使用本应用，即表示您已阅读并同意接受本条款。如您不同意本条款的任何内容，请立即停止使用并卸载本应用。

## 二、您对数据的使用授权

本应用的所有记录（周期参数、打卡记录、睡眠时长、心情笔记）仅保存在您的设备本地。请您在设置好周期起点后，**自行负责保管设备与解锁密码**。因设备丢失、他人共用、越狱等原因导致数据外泄的，我们无法为您承担相应责任，但会尽力协助您通过「设置 → 数据 → 清空所有打卡记录」或卸载应用来清除数据。

## 三、周期推算的性质

本应用基于您提供的「上次月经开始日」与周期长度推算每日所处阶段。

1. **推算结果不等于医学诊断。** 阶段划分是按一般规律做的估算，实际周期长度、阶段时长在个体之间差异很大，排卵也可能因压力、疾病、作息变化而提前或推迟。
2. **推算可能不准确。** 若您的周期本身不规律，请不要把本应用的推算当作事实依据。
3. **不得用于避孕目的。** 本应用无法预测具体排卵日，也未获得医疗器械认证，**不可作为避孕方法的依据**。如需避孕，请咨询专业医生或采用可靠方法。
4. **数据由您输入。** 若您输入的起始日或周期长度不准确，后续所有推算都会随之偏移。

## 四、健康建议的性质与免责

1. 本应用提供的阶段说明、运动清单、作息与饮食建议，均为**面向一般人群的一般性健康科普**，**仅供参考，不构成医疗建议、诊断或治疗方案**。
2. 本应用**不是医疗器械**，未经任何医疗器械注册或认证。
3. 我们不对您依据本应用内容采取的行动产生的后果负责。身体不适、月经异常、有用药需求或处于特殊生理状态（如孕期、哺乳期、多囊卵巢综合征等）时，请咨询专业医生。
4. 若您出现大量出血、剧烈腹痛等紧急症状，请立即就医，不要依赖本应用。
