# 隐私政策

最后更新日期：2026-11-12

本隐私政策适用于「悦她」（Yueta）iOS 应用（Bundle ID：`com.yuanjingtech.yueta`，以下简称「本应用」），由 Yuanjing Tech（以下简称「我们」）提供。

## 一、一句话说明

**悦她把你的数据留在你的手机上。** 本应用没有账号体系、不联网、不收集、不上传、不共享你的任何个人数据；所有记录都只保存在本机的应用沙盒内，只有你自己能看到。

## 二、我们处理哪些信息

以下信息由你在使用过程中主动填写，仅保存在你的设备本地：

| 信息类型 | 具体内容 | 用途 |
|---|---|---|
| 周期信息 | 上次月经开始日、周期长度、各阶段天数 | 推算今天所处的周期阶段与后续日期 |
| 打卡记录 | 每日注意事项完成情况、具体运动项目完成情况 | 展示今日进度、日历标记与统计 |
| 睡眠记录 | 你手动填写的当日睡眠时长 | 生成月度睡眠洞察 |
| 心情笔记 | 你在「今日心情记录」中写的文字 | 仅回显给你本人，用于回顾 |
| 偏好设置 | 提醒开关与时间、每日目标、界面配色 | 按你的偏好呈现界面与提醒 |

**这些信息不会被发送到任何服务器。** 本应用不包含任何网络请求代码，未集成任何第三方 SDK（无统计、无广告、无崩溃上报、无推送服务商），也不使用 iCloud 或 CloudKit 同步。

> 我们不会收集：姓名、手机号、邮箱、身份证件、位置、通讯录、照片、剪贴板、设备标识符（IDFA/IDFV）、健康 App 数据，也不会进行任何形式的用户画像或跨应用追踪。

## 三、数据存储在哪里

1. **本机应用沙盒**：上述数据以 `JSON` 序列化后存放在 iOS 的 `UserDefaults` 中，位于本应用的私有沙盒内，其他 App 无法读取。
2. **未加密但受系统保护**：数据本身未额外加密（仅为序列化存储），其安全性依赖 iOS 的沙盒隔离与设备锁屏加密。因此我们建议你开启设备密码 / Face ID / Touch ID。
3. **系统备份**：如果你开启了 iCloud 备份或使用电脑备份 iPhone/iPad，本应用的数据可能随系统备份一起被包含在内。该备份由 Apple（或你自己）管理，不经过我们的服务器。你可以在 iOS「设置 → Apple ID → iCloud → 管理账户存储 → 备份」中关闭备份，或使用电脑端工具排除本应用。
4. **换设备不会自动迁移**：因为不做云同步，换新设备后需要重新设置一次周期起点，历史打卡记录不会自动带过去。

## 四、系统权限

本应用只申请一项权限：

- **通知**：用于发送每日提醒、阶段开始提醒与早睡提醒。这些通知**全部在本机生成并定时触发**（本地通知，最多提前排程 60 天），不经过任何推送服务器。你可以随时在应用内「设置 → 提醒设置」关闭，或在 iOS「设置 → 通知 → 悦她」中关闭；拒绝授权不影响其他功能，只是收不到提醒。

本应用**不申请**相机、麦克风、相册、定位、通讯录、日历、健康数据等任何其他权限。

## 五、分享功能说明

「指南」页提供分享按钮，调用 iOS 系统分享面板，用于把四阶段的通用说明文字转发给亲友。该文案是固定的科普内容，**不包含你的任何个人记录**（不含日期、打卡、睡眠、心情笔记）。分享目标与是否分享完全由你在系统面板中选择，本应用不参与传输、不记录分享行为。

## 六、我们如何共享、转让、公开披露信息

- **不出售**：我们不出售你的任何信息。
- **不共享**：我们不会向任何第三方共享你的信息，因为我们既不收集也不持有这些信息。
- **不转让**：不存在因合并、收购而转移数据的情形——数据从未离开你的设备。
- **不公开披露**：我们没有任何可披露的数据副本。

## 七、你的权利

由于数据只存在你的设备上，你可以直接、完整地行使以下权利，无需向我们申请：

| 权利 | 操作方式 |
|---|---|
| 查阅、导出 | 在应用内各页面直接查看；截图或使用系统「分享」即可带走 |
| 更正 | 在「设置」修改周期参数；在「今日」修改当日打卡、睡眠与笔记 |
| 删除单条记录 | 取消对应勾选；清空心情笔记后保存 |
| 删除全部打卡记录 | 「设置 → 数据 → 清空所有打卡记录」 |
| 删除全部数据 | 卸载本应用，系统会一并清除其沙盒内所有数据（含设置） |
| 撤回通知授权 | 应用内关闭提醒开关，或 iOS「设置 → 通知 → 悦她」 |

删除后不可恢复，我们也没有备份可以帮你找回——这正是「数据只在你手上」的代价与保证。

## 八、敏感个人信息的特别说明

月经周期、睡眠与心情记录属于敏感个人信息。我们对此的处理原则是：**不收集、不上传、不留存于任何服务器**，全部处理均在你的设备本地完成。请你也妥善保管设备与锁屏密码，避免他人通过你的手机查看这些内容。

## 九、儿童隐私

本应用不面向未满 14 周岁的儿童，也不会主动向其提供服务。由于本应用不收集任何信息、不存在账号与服务器，因此不存在「儿童个人信息被收集或泄露」的情形。若你是不满 14 周岁的用户，请在监护人指导下使用，或不要使用本应用。

## 十、数据安全

我们采取的措施是「从源头减少风险」：不联网、不设账号、不接第三方 SDK、不申请多余权限，数据不出设备。这意味着不存在服务器被拖库、传输被窃听、第三方转卖等风险。设备侧的丢失、越狱、他人共用等情况需要你通过系统密码与生物识别来防护。

## 十一、医疗免责

本应用提供的周期阶段说明、运动与作息建议均为一般性健康科普，**仅供参考，不构成医疗建议，也不能用于诊断、治疗或避孕**。个体差异很大，请以自身感受为准；如有持续不适、月经异常或用药需求，请咨询专业医生。

## 十二、本政策的变更

若未来版本新增联网、云同步、账号、订阅或第三方 SDK 等功能，我们会在功能上线前更新本政策，明确新增的数据类型、用途与共享对象，并在应用内显著提示。继续使用即表示你接受更新后的政策；如不接受，你可以停止使用并卸载本应用。

本政策的历次版本与更新日期会保留在本页面。
