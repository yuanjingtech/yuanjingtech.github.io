# 隐私政策

最后更新日期：2026-11-12

本隐私政策适用于「回光」（Huiguang）iOS 应用（Bundle ID：`com.yuanjingtech.xiuxian`，以下简称「本应用」），由 Yuanjing Tech（以下简称「我们」）提供。

## 一、一句话说明

**回光把你的数据留在你的手机上。** 本应用没有账号体系、不联网、不收集、不上传、不共享你的任何个人数据；所有记录都只保存在本机的应用沙盒内，只有你自己能看到。

## 二、我们处理哪些信息

以下信息由你在使用过程中主动填写或由练习产生，仅保存在你的设备本地：

| 信息类型 | 具体内容 | 用途 |
|---|---|---|
| 修习者称呼 | 你在「设置」中填写的称呼（默认「修习者」） | 界面上的称呼展示，不具有身份识别作用 |
| 练习进度 | 累计静坐分钟、累计修为、当前境界、静坐次数、连续打卡天数 | 计算课程章次与境界的解锁状态 |
| 静坐记录 | 每次静坐的日期、课程名、章次名、时长、所得修为 | 生成静坐日志、七日柱状图与统计 |
| 日用打卡 | 每日功课的勾选情况与对应日期 | 展示今日进度、日历标记与连续天数 |
| 练习笔记 | 你在「练习笔记」中写的文字 | 仅回显给你本人，用于中性的自我观察 |
| 今日安排 | 你自选的静坐计划 | 在「今日」页展示当天安排 |
| 偏好设置 | 语音开关与语速、每日提醒开关与提醒时间 | 按你的偏好呈现引导语音与提醒 |

**这些信息不会被发送到任何服务器。** 本应用不包含任何网络请求代码，未集成任何第三方 SDK（无统计、无广告、无崩溃上报、无推送服务商），也不使用 iCloud 或 CloudKit 同步。

> 我们不会收集：姓名、手机号、邮箱、身份证件、位置、通讯录、照片、剪贴板、设备标识符（IDFA/IDFV）、健康 App 数据，也不会进行任何形式的用户画像或跨应用追踪。

**关于「境界」与「修为」**：本应用中的境界、修为、突破、渡劫均为**游戏化虚构设定**，只是由上述本地数值驱动的界面表现，不代表任何修炼成就、宗教修证成效或现实效果，也不构成对你的健康或身心状态的测量与判断。

## 三、数据存储在哪里

1. **本机应用沙盒**：上述数据以 `JSON` 序列化后存放在 iOS 的 `UserDefaults` 中（存储键 `xiuxian.state.v1`），位于本应用的私有沙盒内，其他 App 无法读取。
2. **未加密但受系统保护**：数据本身未额外加密（仅为序列化存储），其安全性依赖 iOS 的沙盒隔离与设备锁屏加密。因此我们建议你开启设备密码 / Face ID / Touch ID。
3. **系统备份**：如果你开启了 iCloud 备份或使用电脑备份 iPhone/iPad，本应用的数据可能随系统备份一起被包含在内。该备份由 Apple（或你自己）管理，不经过我们的服务器。你可以在 iOS「设置 → Apple ID → iCloud → 管理账户存储 → 备份」中关闭备份，或使用电脑端工具排除本应用。
4. **换设备不会自动迁移**：因为不做云同步，换新设备后需要重新设置，历史静坐记录与笔记不会自动带过去。

## 四、系统权限

本应用只申请一项权限：

- **通知**：用于在你设定的时间发送每日静坐提醒。该通知**全部在本机生成并定时触发**（本地通知，按日历重复触发），不经过任何推送服务器。通知内容为应用内固定文案，不包含你的任何个人记录。你可以随时在应用内「设置 → 每日本地提醒」关闭，或在 iOS「设置 → 通知 → 回光」中关闭；拒绝授权不影响其他功能，只是收不到提醒。

本应用**不申请**相机、麦克风、相册、定位、通讯录、日历、健康数据等任何其他权限。

## 五、语音引导说明

静坐引导语音由 iOS 系统的语音合成框架（`AVSpeechSynthesizer`）在**本机**实时合成并播放，使用系统内置中文（zh-CN）语音。朗读内容为应用内置的固定引导文本，**不包含你的任何个人记录**；合成过程不产生网络请求，不录制或上传音频。你可以在「设置」中关闭语音或调整语速；关闭后本应用完全不使用语音功能。

> 部分系统语音包可能由 iOS 按需从 Apple 下载安装，该行为由 Apple 的系统更新机制完成，不涉及本应用传输你的任何信息。

## 六、我们如何共享、转让、公开披露信息

- **不出售**：我们不出售你的任何信息。
- **不共享**：我们不会向任何第三方共享你的信息，因为我们既不收集也不持有这些信息。
- **不转让**：不存在因合并、收购而转移数据的情形——数据从未离开你的设备。
- **不公开披露**：我们没有任何可披露的数据副本。

本应用不含广告、不含 App 内购买项目，也不基于你的数据做个性化推荐或用户画像。

## 七、你的权利

由于数据只存在你的设备上，你可以直接、完整地行使以下权利，无需向我们申请：

| 权利 | 操作方式 |
|---|---|
| 查阅、导出 | 在应用内「今日」「日用」「境界」各页直接查看；截图即可带走 |
| 更正 | 在「设置」修改称呼、语音与提醒偏好；在「日用」取消打卡勾选即撤回当日修为 |
| 删除单条记录 | 清空对应练习笔记后保存；取消对应功课勾选 |
| 删除全部数据 | 应用内「设置 → 重置全部静坐数据」，或卸载本应用（系统会一并清除沙盒内所有数据） |
| 撤回通知授权 | 应用内关闭提醒开关，或 iOS「设置 → 通知 → 回光」 |

删除后不可恢复，我们也没有备份可以帮你找回——这正是「数据只在你手上」的代价与保证。

## 八、练习笔记的特别说明

你在「练习笔记」中写下的文字可能包含你主动记录的身心感受。我们对此的处理原则是：**不收集、不上传、不留存于任何服务器**，全部处理均在你的设备本地完成，仅回显给你本人。请你也妥善保管设备与锁屏密码，避免他人通过你的手机查看这些内容。

## 九、儿童隐私

本应用不面向未满 14 周岁的儿童，也不会主动向其提供服务。由于本应用不收集任何信息、不存在账号与服务器，因此不存在「儿童个人信息被收集或泄露」的情形。若你是不满 14 周岁的用户，请在监护人指导下使用，或不要使用本应用。

## 十、数据安全

我们采取的措施是「从源头减少风险」：不联网、不设账号、不接第三方 SDK、不申请多余权限，数据不出设备。这意味着不存在服务器被拖库、传输被窃听、第三方转卖等风险。设备侧的丢失、越狱、他人共用等情况需要你通过系统密码与生物识别来防护。

## 十一、医疗免责

本应用是传统文化题材的静坐练习工具与游戏化习惯养成工具，**不是宗教仪轨指导，也不是医疗器械**，不宣称任何诊断、治疗、缓解或保健效果，也不替代专业医疗或心理方面的意见。引导内容只涉及安坐、放松、自然呼吸与注意力收摄，不做任何成效承诺；境界与渡劫纯属虚构游戏化演出。

练习时请**呼吸自然、不憋气**；如感不适请**立即停止**。有身心健康方面情况者，请先咨询专业人士再决定是否练习。

本应用不占卜、不预测个人运势、不宣扬封建迷信。

## 十二、本政策的变更

若未来版本新增联网、云同步、账号、订阅或第三方 SDK 等功能，我们会在功能上线前更新本政策，明确新增的数据类型、用途与共享对象，并在应用内显著提示。继续使用即表示你接受更新后的政策；如不接受，你可以停止使用并卸载本应用。

本政策的历次版本与更新日期会保留在本页面。
