# OpenCode：开源 AI 编码代理

OpenCode 是一个开源的 AI 编码代理，帮助你在终端、IDE 或桌面应用中编写代码。

## 核心特性

### 多平台支持
- **LSP 自动加载**：自动为 LLM 加载正确的 LSP
- **多会话支持**：在同一项目上并行启动多个代理
- **链接分享**：分享任意会话链接以便参考或调试
- **Claude Pro 集成**：使用 Anthropic 登录你的 Claude Pro 或 Max 账户

### 灵活的模型选择
- **任意模型**：通过 Models.dev 支持 75+ LLM 提供商，包括本地模型
- **任何编辑器**：提供终端界面、桌面应用和 IDE 扩展

## 数据指标

- **50,000** GitHub 星标
- **500** 贡献者
- **6,500+** 代码提交
- **650,000** 月活跃开发者

## 隐私优先

OpenCode 不存储任何代码或上下文数据，使其能够在对隐私敏感的环境中运行。

## 快速开始

```bash
curl -fsSL https://opencode.ai/install | bash
```

## 成本

OpenCode 免费使用，支持免费模型，或连接任何提供商的模型（包括 Claude、GPT、Gemini 等）。

## 开源

OpenCode 是完全开源的，可在 [GitHub](https://github.com/anomalyco/opencode) 上获取源代码。
