# 用户条款

最后更新日期：2026-11-12

本用户条款适用于「我的知识宇宙」（Knowledge Universe）iOS 应用（Bundle ID：`com.yuanjingtech.knowledge`，以下简称「本应用」），由 Yuanjing Tech（以下简称「我们」）提供。

欢迎使用本应用。通过下载、安装或使用本应用，您同意遵守以下用户条款。如您不同意任何条款，请立即停止使用本应用并卸载。

本应用**完全免费**，不含内购项目、订阅、付费墙或广告，也不需要注册或登录账号。下载即用。

## 二、用户行为规范

使用本应用时，您同意：

1. 不得用于任何非法目的；
2. 不得干扰本应用的正常运行；
3. 不得尝试反向工程、反编译或破解本应用；
4. 不得利用本应用从事任何侵犯他人权益的行为。

本应用没有账号、没有排行榜、没有社交功能，也没有用户生成内容或用户间互动，因此不存在冒用他人身份、骚扰他人或传播不当内容的情形。

3. 本应用内置的知识条目为原创整理成果；其条目中提及的第三方典籍、文献与作品，其著作权归各自权利人所有。本应用仅作介绍与索引，不主张对这些内容的任何权利。

## 四、第三方链接

本应用条目详情中包含指向第三方网站的免费公开资源链接。

1. 点击链接时，**iOS 会将其交给系统默认浏览器打开**，本应用不托管、不代理、不控制这些第三方网站的内容。
2. 第三方网站的内容、可用性、收费方式与隐私政策由其自身负责，与我们无关。
3. 您与第三方网站之间的任何交易、注册或数据处理行为均发生在该第三方，与我们无关；请在使用前审阅其隐私政策。
4. 含 `{q}` 占位符的检索类链接会自动以该知识条目的**标题**作为检索词补全。标题属于知识条目的公开名称，不是您的个人数据。

1. 本应用按「现状」提供，我们不对其适用性、可靠性或准确性作出任何明示或暗示的保证。
2. 在法律允许的最大范围内，我们不对因使用或无法使用本应用而产生的任何间接、偶然或后果性损害承担责任。
3. 本应用提供的知识简介与学习建议属于**一般性科普与学习辅助**，仅供参考，**不构成医疗、心理、法律、财务或其他任何专业建议**，亦不应用于诊断、治疗或决策。

1. 您的打卡记录、学习计划、收藏与偏好设置**仅保存在您的设备本机**，我们无法访问、也无法恢复这些数据。
2. 本应用**不联网、不收集、不上传、不共享**您的任何个人数据，不含第三方 SDK，不申请任何系统权限。详见《[隐私政策](/zhishichangyu/privacy/)》。
3. 卸载本应用会一并清除其在本机沙盒内的全部数据；由于我们不持有任何副本，**这些数据无法找回**。如果您希望保留学习记录，请在卸载前自行截图或导出。
4. 换用新设备时，因本应用不做云同步，历史记录与偏好**不会自动迁移**，需要您重新设置。
