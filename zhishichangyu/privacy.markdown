# 隐私政策

最后更新日期：2026-11-12

本隐私政策适用于「我的知识宇宙」（Knowledge Universe）iOS 应用（Bundle ID：`com.yuanjingtech.knowledge`，以下简称「本应用」），由 Yuanjing Tech（以下简称「我们」）提供。

## 一、一句话说明

**本应用把你的数据留在你的手机上。** 本应用没有账号体系、不上传、不收集、不共享你的任何个人数据；所有学习记录都只保存在本机的应用沙盒内，只有你自己能看到。

## 二、我们处理哪些信息

以下信息由你在使用过程中主动产生，仅保存在你的设备本地：

| 信息类型 | 具体内容 | 用途 |
|---|---|---|
| 打卡记录 | 每天的完成情况、学习分钟数、连续打卡天数、累计学习时长 | 展示今日进度、日历标记与学习统计 |
| 今日学习计划 | 当天安排的 3 条知识任务及其完成状态、预计时长 | 生成并维护「今日 2 小时」学习包 |
| 顺延队列 | 跨天未完成任务及其顺延来源日期、顺延次数 | 把昨天没学完的任务排到今天，不丢任务 |
| 已学与收藏 | 你标记为「已学」和「收藏」的知识点编码 | 排除已学内容、收藏夹展示 |
| 偏好设置 | 偏好领域（16 个一级域多选）、是否排除已学、是否只抽有免费链接的条目 | 按你的偏好决定盲盒抽取范围 |
| 盲盒记录 | 最近一次抽中的知识点编码 | 避免连续抽到同一条 |

**这些信息不会被发送到任何服务器。** 本应用不包含任何网络请求代码，未集成任何第三方 SDK（无统计、无广告、无崩溃上报、无推送服务商），也不使用 iCloud 或 CloudKit 同步。

> **关于数据出境**：由于全部数据仅保存在您自己的设备上、从不传输至任何服务器（境内或境外），本应用**不存在个人信息出境**的情形，不涉及数据出境安全评估、认证或标准合同备案。

> 我们不会收集：姓名、手机号、邮箱、身份证件、位置、通讯录、照片、剪贴板、设备标识符（IDFA/IDFV）、健康 App 数据、通讯内容，也不会进行任何形式的用户画像或跨应用追踪。

## 三、数据存储在哪里

1. **本机应用沙盒**：上述数据以 `JSON` 序列化后存放在 iOS 的 `UserDefaults` 中，位于本应用的私有沙盒内，其他 App 无法读取。
2. **未加密但受系统保护**：数据本身未额外加密（仅为序列化存储），其安全性依赖 iOS 的沙盒隔离与设备锁屏加密。因此我们建议你开启设备密码 / Face ID / Touch ID。
3. **系统备份**：如果你开启了 iCloud 备份或使用电脑备份 iPhone/iPad，本应用的数据可能随系统备份一起被包含在内。该备份由 Apple（或你自己）管理，不经过我们的服务器。你可以在 iOS「设置 → Apple ID → iCloud → 管理账户存储 → 备份」中关闭备份，或使用电脑端工具排除本应用。
4. **换设备不会自动迁移**：因为不做云同步，换新设备后需要重新设置一次偏好，历史打卡记录不会自动带过去。
5. **删除 App 即删除全部数据**：卸载本应用时，iOS 会一并清除其沙盒内的全部数据（含设置与记录）。

## 四、系统权限

**本应用不申请任何系统权限。** 不需要通知、相机、麦克风、相册、定位、通讯录、日历、通讯录或健康数据授权，也不需要访问剪贴板或跟踪权限。

本应用内没有推送、提醒、拍照、录音、定位或健康数据读取等功能；所有功能均可离线使用。

## 五、第三方链接说明

本应用内置 673 条知识条目，每条附带 3–5 个免费公开资源链接（维基百科、Internet Archive、各类开放获取站点等）。当你点击某条链接时，**iOS 会把它交给系统默认浏览器（如 Safari）打开**：

- 本应用只负责跳转到该网址，**不会把你在本应用中的任何记录、笔记、打卡数据或偏好一并传递过去**；
- 该链接指向的是**第三方网站**，其隐私政策、数据处理方式与内容由该第三方自行负责，与我们无关；
- 带 `{q}` 占位符的检索类链接，会自动用该条知识点的**标题**作为检索词补全。标题属于知识条目的公开名称，不是你的个人数据；
- 点击外部链接意味着你将离开本应用，该第三方可能会按其自身政策收集浏览信息（例如 IP 地址、Cookie）。如涉及个人信息，请同时查阅该第三方的隐私政策。

## 六、知识内容与来源说明

本应用内置的知识数据（知识点、简介、关键词、代表典籍、免费链接、衍生学习建议）均为**随 App 一起分发的静态内容**，保存在 App 包内：

- 这些内容**不包含任何用户数据**，也不因你的使用而变化；
- 内容的免费程度标注（如「免费全文 / 开放获取 / 部分免费 / 需免费注册 / 免费旁听」）反映的是**链接所指向资源当时的状况**，可能随时间变化；
- 部分链接指向需免费注册或付费的资源，App 已在链接名与说明中标注，但最终以该资源方当时的规则为准。

## 七、我们如何共享、转让、公开披露信息

- **不出售**：我们不出售你的任何信息。
- **不共享**：我们不会向任何第三方共享你的信息，因为我们既不收集也不持有这些信息。
- **不转让**：不存在因合并、收购而转移数据的情形——数据从未离开你的设备。
- **不公开披露**：我们没有任何可披露的数据副本。

> 若未来版本接入第三方统计、广告或推送服务，我们会**在功能上线前**更新本政策，明确新增的数据类型、用途与共享对象，并在应用内显著提示。

## 八、你的权利

由于数据只存在你的设备上，你可以直接、完整地行使以下权利，无需向我们申请：

| 权利 | 操作方式 |
|---|---|
| 查阅、导出 | 在应用内「打卡记录」「全览」「知识库」各页面直接查看；截图或使用系统「分享」即可带走 |
| 更正打卡与分钟数 | 在「今日」页取消/勾选对应任务，用 `+15 / −15 分钟` 修正时长 |
| 删除单条学习记录 | 在「今日」页取消该任务的勾选；取消「收藏」标签 |
| 删除全部记录 | 卸载本应用，系统会一并清除其沙盒内所有数据（含设置） |
| 撤回偏好 | 在「盲盒」页重新设置偏好领域与过滤开关 |

删除后不可恢复，我们也没有备份可以帮你找回——这正是「数据只在你手上」的代价与保证。

## 九、儿童隐私

本应用不面向未满 14 周岁的儿童，也不会主动向其提供服务。由于本应用不收集任何信息、不存在账号与服务器，因此不存在「儿童个人信息被收集或泄露」的情形。若你是不满 14 周岁的用户，请在监护人指导下使用，或不要使用本应用。

## 十、数据安全

我们采取的措施是「从源头减少风险」：不联网、不设账号、不接第三方 SDK、不申请任何系统权限，数据不出设备。这意味着不存在服务器被拖库、传输被窃听、第三方转卖等风险。设备侧的丢失、越狱、他人共用等情况需要你通过系统密码与生物识别来防护。

## 十一、内容免责与口径提醒

- 本应用提供的知识简介与学习建议属于**一般性科普与学习辅助**，仅供参考，不构成任何形式的诊断、治疗或专业建议。
- 学科分类以《研究生教育学科专业目录（2022 年）》为主干，编号仅作索引，**以官方最新版为准**。
- 「三教九流 / 上中下九流 / 三百六十行」等民间分类历代版本互相冲突，App 中取较通行一说并标注「版本不一」；分类法是整理工具，不是知识的边界——这张表是地图，不是领土。
- 外部免费资源的免费范围可能随时间变化，需注册或收费的部分已在链接说明中标出。

## 十二、本政策的变更

若未来版本新增联网、云同步、账号、订阅或第三方 SDK 等功能，我们会在功能上线前更新本政策，明确新增的数据类型、用途与共享对象，并在应用内显著提示。继续使用即表示你接受更新后的政策；如不接受，你可以停止使用并卸载本应用。

本政策的历次版本与更新日期会保留在本页面。
